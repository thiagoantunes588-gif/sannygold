# Manual de uso diario - Sistema SannyGold

Este manual orienta a equipe no uso do sistema para rotina administrativa, operacional e financeira. O fluxo recomendado e usar o painel internamente, gerar PDF quando necessario e compartilhar links de endereco somente quando ajudarem a operacao.

## Melhor forma de usar

1. Entrar no sistema no inicio do dia.
2. Conferir a Central de trabalho do dia.
3. Resolver pendencias criticas antes de criar novas rotas.
4. Cadastrar ou revisar clientes, eventos, equipamentos e financeiro.
5. Validar a operacao antes de gerar rota.
6. Gerar PDF da rota quando houver despacho.
7. Usar links de endereco para conferencia ou envio interno quando necessario.
8. Fazer fechamento e backup no fim do dia.

## Entrar no sistema

1. Abra o link publicado do sistema.
2. Clique em Configuracoes.
3. Informe email e senha.
4. Confira seu nome e funcao no topo.
5. Use sempre o seu proprio usuario.

Regras importantes:

- Nao compartilhe senha.
- Nao use usuario administrador para rotina diaria se houver usuario proprio.
- Ao terminar em computador compartilhado, saia da conta.

## Tela inicial

Use a tela inicial como ponto de partida.

Ela mostra:

- Central de trabalho do dia.
- Eventos de hoje.
- Rotas e PDF.
- Cobrancas vencidas.
- Pendencias e alertas.
- Painel de controle e prevencao.
- Busca global.
- Atalhos de relatorios.

Se aparecer alerta vermelho, resolva antes de liberar a operacao.

## Busca global

Use a busca para encontrar rapidamente:

- cliente;
- telefone;
- evento;
- equipamento;
- placa;
- material de estoque;
- numero de NF;
- cobranca financeira.

Quando encontrar o item, clique no resultado para abrir o modulo correto.

## Clientes

Use Novo cliente para cadastrar ou atualizar dados.

Campos essenciais:

- nome do cliente;
- contato;
- telefone;
- endereco;
- latitude e longitude;
- tipo de cliente;
- equipamento vinculado quando ja existir;
- valor do servico;
- informacao de nota fiscal quando aplicavel.

Boa pratica:

- antes de criar cliente novo, pesquise nome, telefone e CPF/CNPJ;
- confira duplicidades apontadas no Painel de controle e prevencao;
- mantenha telefone e endereco atualizados.

## Eventos

Use Novo evento para criar uma operacao.

Passos:

1. Informe nome do evento.
2. Informe data inicial e final.
3. Vincule clientes.
4. Vincule veiculos.
5. Revise o checklist.
6. Salve.

Checklist recomendado:

- Cliente confirmado.
- Equipamentos separados.
- Documentos conferidos.
- Equipe alinhada.
- Financeiro validado.

## Preparar despacho

Use o botao Preparar despacho no painel.

Antes de liberar:

1. Verifique se a rota esta validada.
2. Confira se nao ha bloqueios.
3. Confira veiculo.
4. Confira equipamentos.
5. Confira contato do cliente.
6. Gere ou abra o PDF da rota.
7. Revise links de endereco quando forem usados.

Nao foi criado um novo impresso por evento. A rotina continua usando os PDFs e relatorios existentes do sistema.

## Gerar rota e PDF

1. Abra a aba Operacao.
2. Selecione o evento.
3. Clique em Validar operacao.
4. Corrija pendencias, se houver.
5. Clique em Gerar rota.
6. Abra o PDF da rota.
7. Se necessario, abra o mapa real ou link do Google Maps.

Use o PDF para entrega impressa ou envio interno.

## Links de endereco

Os links de endereco ajudam na conferencia e no envio interno.

Use quando:

- o endereco for dificil;
- houver mais de uma parada;
- a equipe precisar abrir direto no mapa;
- for necessario conferir sequencia da rota.

Sempre confira se o endereco do cadastro esta correto antes de compartilhar.

## Frota e equipamentos

Use a aba Frota e equipamentos para:

- cadastrar veiculo;
- cadastrar equipamento;
- consultar disponibilidade;
- registrar placa;
- enviar equipamento para manutencao;
- registrar motivo da indisponibilidade;
- liberar equipamento apos manutencao.

Antes de vincular ao evento, confira se o equipamento esta disponivel.

## Manutencao preventiva

Use os alertas de manutencao para evitar problema no dia do evento.

Registre:

- motivo;
- previsao de liberacao;
- custo;
- observacao tecnica.

Equipamento em manutencao ou indisponivel nao deve ser usado no evento.

## Almoxarifado

Use para materiais internos.

Acoes principais:

- adicionar item;
- repor estoque;
- dar baixa;
- ajustar quantidade;
- consultar historico;
- exportar PDF.

Itens baixos ou zerados aparecem nas pendencias criticas.

## Financeiro

Area protegida por permissao.

Use para:

- contas a receber;
- fluxo de caixa;
- alertas de cobranca;
- inadimplencia;
- DRE mensal;
- DRE por evento;
- financeiro por cliente;
- fechamento financeiro mensal.

O anexo de comprovante e opcional.

## Contas a receber

Confira:

- vencidas;
- vencendo hoje;
- proximos 7 dias;
- proximos 30 dias;
- pagas.

Antes de nova locacao, confira se o cliente tem inadimplencia.

## Fechamento financeiro mensal

No fim do mes:

1. Revise contas a receber.
2. Revise fluxo de caixa.
3. Confira notas fiscais.
4. Confira impostos provisionados.
5. Gere fechamento financeiro mensal.
6. Baixe o PDF do fechamento.
7. Envie os relatorios ao contador.

## Relatorios

Relatorios recomendados:

- evento;
- cliente;
- financeiro mensal;
- equipamentos;
- inadimplencia;
- estoque baixo;
- rentabilidade por tipo de servico.

Use PDF para conferencia e Excel quando precisar tratar dados.

## Fechamento diario e backup

No fim do dia:

1. Confira pendencias criticas.
2. Confira retornos e equipamentos.
3. Baixe o fechamento diario.
4. Baixe o backup do sistema.
5. Salve o arquivo em local seguro.

Antes de grandes alteracoes, baixe backup.

## Atualizacoes pelo Codex

Para pedir melhorias futuras, diga aqui no Codex exatamente o que precisa mudar.

Exemplos:

- Adicionar novo campo no cliente.
- Ajustar texto do PDF.
- Criar novo relatorio.
- Alterar regra de cobranca.
- Mudar permissao de usuario.
- Publicar nova versao.

Fluxo recomendado:

1. Pedir a mudanca no Codex.
2. O Codex altera o sistema.
3. Rodar testes.
4. Publicar nova versao.
5. Equipe usa o mesmo link atualizado.

## Regras rapidas

- Cadastre com calma para evitar duplicidade.
- Pesquise antes de criar novo cliente.
- Valide antes de gerar rota.
- Confira PDF antes de enviar.
- Nao use equipamento indisponivel.
- Mantenha financeiro atualizado.
- Baixe backup diariamente.
- Registre manutencao com motivo e previsao.
