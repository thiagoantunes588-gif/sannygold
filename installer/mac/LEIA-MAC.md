# SannyGold no Mac

Use esta pasta somente em computadores Mac.

Arquivo esperado:

- `SannyGold Sistema.app`
- ou `SannyGold-Sistema-Mac.zip`

Como usar:

1. Abra o app `SannyGold Sistema.app`.
2. Se estiver em `.zip`, descompacte antes de abrir.
3. O sistema roda localmente no Mac.
4. O Dropbox deve receber apenas backups `.zip` e instaladores.

Nao use o instalador `.exe` do Windows no Mac.
