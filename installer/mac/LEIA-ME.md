# SannyGold no Mac

Use esta pasta somente em computadores Mac.

Arquivos esperados em `Instalador/`:

- `SannyGold Sistema.app`
- `SannyGold-Sistema-Mac.zip`

Como usar:

1. Abra `Mac/Instalador/`.
2. Se recebeu o `.zip`, descompacte antes de abrir.
3. Abra `SannyGold Sistema.app`.
4. O sistema roda no computador e usa o Dropbox apenas para backups `.zip` e instaladores.

A pasta `Atualizações/` fica reservada para pacotes de atualizacao futuros.

Nao use o instalador `.exe` do Windows no Mac.
