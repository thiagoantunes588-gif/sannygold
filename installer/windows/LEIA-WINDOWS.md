# SannyGold no Windows

Use esta pasta somente em computadores Windows 10 ou 11.

Arquivos esperados em `Instalador/`:

- `SannyGold-Sistema-Windows-Setup.exe`
- `SannyGold-Sistema-Windows-Portable.zip`

Como instalar:

1. Abra `Windows/Instalador/`.
2. Dê dois cliques em `SannyGold-Sistema-Windows-Setup.exe`.
3. Mantenha marcada a opção `Criar atalho na Área de Trabalho`.
4. Ao final, mantenha marcada a opção `Abrir SannyGold Sistema após instalar`.
5. Abra o sistema pelo atalho `SannyGold Sistema`.

O sistema sera instalado em `%LOCALAPPDATA%\SannyGold Sistema`.

O banco ativo e as pastas `data`, `uploads` e `preview` ficam no computador. O Dropbox deve receber apenas instaladores e backups `.zip`.

Use o `.zip` portátil apenas para suporte técnico. Para instalação normal, use sempre o `.exe`.

Na versão portátil, extraia o `.zip`, abra a pasta `SannyGold Sistema` e dê dois cliques em `abrir-sistema.bat`.

Nao use o app `.app` do Mac no Windows.
