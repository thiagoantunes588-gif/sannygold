# SannyGold no Windows

Use esta pasta somente em computadores Windows 10 ou 11.

Arquivos esperados em `Instalador/`:

- `SannyGold-Sistema-Windows-Setup.exe`
- `SannyGold-Sistema-Windows-Portable.zip`

Como instalar:

1. Abra `Windows/Instalador/`.
2. Para uso normal, de dois cliques em `SannyGold-Sistema-Windows-Setup.exe`.
3. Mantenha marcada a opcao de criar atalho na Area de Trabalho.
4. Ao final, abra o sistema pelo atalho `SannyGold Sistema`.

Use o `.zip` portatil apenas para suporte tecnico ou contingencia. Nesse caso,
extraia o arquivo em uma pasta local fora do Dropbox, abra a pasta `SannyGold Sistema`
e de dois cliques em `abrir-sistema.bat`.

A pasta `Atualizações/` fica reservada para pacotes de atualizacao futuros.

O banco ativo, `data`, `uploads` e `preview` ficam no computador. O Dropbox deve
receber apenas instaladores e backups `.zip`.

Nao use o app `.app` do Mac no Windows.
