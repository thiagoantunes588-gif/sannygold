# Instaladores do Sistema SannyGold

Esta pasta do Dropbox serve apenas para distribuir instaladores e orientar a equipe.
O sistema ativo, o banco de dados, uploads, previews e arquivos de trabalho nao devem
ficar dentro do Dropbox.

Estrutura principal:

- `Mac/`: instalador e atualizacoes para computadores Mac.
- `Windows/`: instalador e pacote portatil para computadores Windows.
- `Celular/`: orientacoes de acesso pelo navegador e atalho na tela inicial.
- `Arquivados/`: pacotes antigos mantidos por historico.
- `_Revisao_Antes_de_Excluir/`: itens separados para revisao antes de qualquer exclusao definitiva.

Use sempre a pasta da plataforma correta. Nao abra arquivos `.exe` no Mac e nao abra
arquivos `.app` no Windows.

O Dropbox deve guardar somente instaladores, documentos de orientacao e backups `.zip`
ja finalizados.
