# Instaladores do Sistema SannyGold

Esta pasta do Dropbox serve apenas para distribuir instaladores e guardar backups `.zip`.

- Se estiver no Mac, abra a pasta `Mac/Instalador/`.
- Se estiver no Windows, abra a pasta `Windows/Instalador/`.
- Se estiver no celular, abra `Celular/` e siga as instrucoes de acesso web.
- Nao tente abrir `.app` no Windows.
- Nao tente abrir `.exe` no Mac.
- Nao execute o sistema ativo de dentro do Dropbox.

O banco ativo, `data/`, `uploads/` e `preview/` devem ficar no computador onde o sistema esta instalado. O Dropbox recebe somente instaladores e backups `.zip`.
